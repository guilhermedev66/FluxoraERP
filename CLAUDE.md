# Fluxora ERP — project instructions

## Git authorship policy (permanent)

All commits in this repository must use only the human owner's Git identity
(the `user.name`/`user.email` already configured for this repo — do not
invent or substitute another identity).

Do not add, for any commit, regardless of which agent or fallback made it:
- `Co-Authored-By:` trailers referencing an AI agent (Claude, Codex,
  Anthropic, OpenAI, Gemini, Antigravity, or any other tool).
- Any other agent-identifying trailer (e.g. session/task links tied to an
  agent).
- Commit message text referencing the agent ("generated by Claude",
  "implemented by Codex", "Claude fallback", "authored by...", etc.).

Commit messages describe only the technical change. Agent handoff/fallback
context belongs in internal orchestration notes (e.g. Maestri notes), never
in the public Git history.

This applies identically during fallback: an agent picking up another
agent's unfinished work still commits with only the human owner's identity
and a plain technical commit message.

Do not rewrite, amend, or force-push existing published commits to apply
this rule retroactively — it applies to all new commits from now on. Any
future cleanup of historical contributors is a separate, explicitly
authorized task.
